# OrbitGuard_AI

## 📌 Sobre o Projeto

O **OrbitGuard_AI** é uma solução tecnológica desenvolvida para monitoramento, prevenção e resposta a eventos climáticos extremos. A plataforma utiliza inteligência artificial, geolocalização e alertas em tempo real para auxiliar usuários em situações de risco, fornecendo informações rápidas e confiáveis sobre áreas vulneráveis, abrigos e rotas seguras.

Este projeto foi desenvolvido para o desafio **GS1**, com foco em inovação, sustentabilidade e proteção da população diante de desastres naturais.

---

## 🎯 Objetivos

* Monitorar eventos climáticos extremos.
* Emitir alertas preventivos para usuários em áreas de risco.
* Identificar regiões vulneráveis utilizando geolocalização.
* Sugerir rotas seguras para evacuação.
* Auxiliar na localização de abrigos próximos.
* Utilizar inteligência artificial para análise de riscos.

---

## 🚀 Funcionalidades

### 👤 Gestão de Usuários

* Cadastro de usuários.
* Login e autenticação.
* Gerenciamento de perfil.

### 📍 Geolocalização

* Identificação da localização do usuário.
* Mapeamento de áreas de risco.
* Visualização de pontos seguros.

### ⚠️ Sistema de Alertas

* Alertas em tempo real.
* Notificações de risco climático.
* Avisos de evacuação preventiva.

### 🤖 Inteligência Artificial

* Análise de dados ambientais.
* Classificação do nível de risco.
* Recomendações automáticas de segurança.

### 🏠 Localização de Abrigos

* Busca de abrigos próximos.
* Exibição de informações sobre cada abrigo.
